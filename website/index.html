[Core Architecture]

Pre-Ingest Mathematical Matrix

01 / I/O CORE

Zero-Dep C++20 Stream

Direct memory-mapped pointer traversal. Processes multi-gigabyte point clouds without copying vertex buffers into intermediate objects.

02 / SANITIZER

Singularity Pruning

Clamps scale explosions (exp(s) > 10⁶), normalizes degenerate quaternions, and validates spherical harmonics degrees (0, 1, 2, 3).

03 / COMPUTE READY

Unreal & Unity Buffer

Prevents GPU crashes, NaN tile corruptions, and rasterizer overdraw before importing assets into custom Niagara or compute shaders.

[Automation Interface]

Model Context Protocol (MCP) Server

GSKit exposes a native MCP server, enabling local coding agents (Cursor, Claude Code, Windsurf) to programmatically audit and repair 3DGS assets inside automated pipelines.
